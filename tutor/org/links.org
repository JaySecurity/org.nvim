Links tie your notes together: to a web page, to a headline of the same
file, to another file, or to an entry by its ID, wherever it moves.
Files can also be attached to an entry. This lesson assumes the first
one (=:Org tutor basics=).

- As before, a {{done}} at the end of an exercise's headline means it is
  done, and {{todo}} that it is not yet. Keys are shown as mapped in your
  config; =<leader>= is ={{leader}}=.
- This is a working copy: =:w= saves your progress and =:Org tutor
  links reset= starts over. Attachments go in a folder next to the
  copy, so your notes stay as they are.
- Stuck? =:Org tutor_hint= shows the keys that solve the exercise at
  the cursor, and =:Org tutor= lists every lesson.

* Lesson 1: links
A link is =[[target][description]]=: only the description shows, and
={{org.toggle_link_display}}= shows the brackets. A target that is not a URL or a
file names a headline (=*Title=) or a =<<target>>= of the file. A new
link goes in after the cursor: at the end of a line, first add a space
with =A=, a space and =<Esc>=.

** 1.1 Follow a link

the headline it names.

* Lesson 2: IDs
A link to a headline by its title breaks when the title changes or the
entry moves to another file. An ID does not: a unique =:ID:= property
that =id:= links find wherever the entry is.

** 2.1 Give an entry an ID
On =Project plan= press ={{org.id_get_create}}=: a =:PROPERTIES:=
drawer with an ID appears under it (={{org.cycle}}= on it shows it).

*** Project plan

** 2.2 Link by ID
On =Project plan= run =:Org id_store_link=: it stores an =id:= link to
the entry. After a space at the end of =Plan:=, press
={{org.insert_last_stored_link}}=. ={{org.open_at_point}}= on the new link jumps to the entry,
even once it is moved to another file.

* Lesson 3: attachments
={{org.attach}}= opens the attachment menu of the entry at the cursor.
Its files go in a folder named after its ID (in =data/= next to this
file), and the entry gets the =ATTACH= tag. =F= in the menu opens the
folder in Neovim, =f= in your file manager.

** 3.1 Attach a new file
On =Receipts= press ={{org.attach}}= and =n=, type =march.txt= and
=<CR>=: a window opens on the new file, in the attachment folder. Type
a line, then =:wq=. =a= in the menu attaches a file you already have.

*** Receipts
- March:

** 3.2 Link to an attachment
After a space at the end of =March:= above, press ={{org.insert_link}}=,
type =attachment:march.txt= and =<CR>= twice. The link finds the file
in the entry's folder; ={{org.open_at_point}}= on it opens the file.
